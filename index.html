    Preparar o vscode.dev

    Aqui você vai escrever código de verdade, como os programadores fazem. Leia cada lição nesta tela e faça no vscode.dev, em outra aba.

    Dica: uma janela de cada lado

    Abra o vscode.dev em uma janela nova (Ctrl + N). No Chromebook, Alt + [ encosta a janela à esquerda e Alt + ] encosta à direita. Assim você lê e digita ao mesmo tempo.

    1Abrir e preparar

    1. Abra o vscode.dev

      Abra uma aba nova (Ctrl + T), escreva vscode.dev e aperte Enter. Não precisa instalar nada.

    2. Abra uma pasta para o seu site

      Clique no menu ☰ (três risquinhos, no canto de cima, à esquerda) → File → Open Folder… (quer dizer Arquivo → Abrir pasta).

      Na janela que abrir: entre em Meus arquivos, clique em Nova pasta, dê o nome meu-site e clique em Abrir.

      O navegador vai pedir permissão. Clique no botão que permite editar os arquivos (por exemplo, Editar arquivos / Edit files). Se aparecer “Do you trust the authors…?”, clique em Yes, I trust the authors.

    3. Crie o arquivo index.html

      Na coluna da esquerda aparece o nome da pasta, MEU-SITE. Passe o mouse em cima dele: aparecem ícones pequenos. Clique no primeiro (New File… = Novo arquivo), escreva index.html e aperte Enter.

    4. Salve sempre

      Aperte Ctrl + S depois de cada mudança. Se a aba do arquivo mostra uma bolinha ● ao lado do nome, é porque ainda não salvou.

    5. Veja a sua página

      Abra o app Arquivos do Chromebook → Meus arquivos → meu-site → dê dois cliques em index.html. A página abre no Chrome.

      Mudou o código? Faça assim: Ctrl + S no vscode.dev → volte na aba da página → Ctrl + R para recarregar.

    O nome precisa terminar em .html

    Só assim o vscode.dev sabe que o arquivo é HTML. Confira no canto de baixo, à direita: tem que estar escrito HTML. Sem isso, o Emmet não funciona.

    O Emmet é um ajudante que já vem dentro do vscode.dev. Você escreve uma abreviação curta, aperta Tab, e ele escreve o código completo para você.

    Exemplo de Emmet

    • pé o nome da tag. O Emmet escreve a tag que abre (<p>) e a que fecha (</p>).
    • |O cursor fica no meio, pronto para você escrever o texto.

    A estrutura da página

    Toda página HTML tem um esqueleto: html, head e body. São caixas, uma dentro da outra.

    html — a página inteira
    head — a cabeça

    Informações sobre a página: o nome da aba, os acentos… Quase nada daqui aparece na tela.

    body — o corpo

    Tudo o que aparece na tela fica aqui dentro: títulos, textos, imagens, listas, links.

    1O Emmet escreve o esqueleto

    Com o arquivo index.html aberto e vazio:

    Atalho Emmet

    Digite!+Tab→vira:

    Por que vira isso?

    • !é o atalho para “página completa”. Em vez de uma tag só, o Emmet escreve o esqueleto inteiro de uma página HTML.

    2Entendendo cada parte

    <!DOCTYPE html>
    Avisa ao navegador: “isto é uma página HTML”. Fica sempre na primeira linha.
    <html lang="en">
    Abre a página inteira. O lang diz o idioma. Troque en (inglês) por pt-BR (português do Brasil).
    <head>
    A cabeça: guarda informações sobre a página.
    <meta charset="UTF-8">
    Faz os acentos e o ç aparecerem certinho.
    <meta name="viewport" …>
    Faz a página funcionar bem na tela do celular.
    <title>Document</title>
    O nome que aparece na aba do navegador. Troque Document pelo nome da sua página.
    <body> … </body>
    O corpo. Todo o conteúdo que aparece na tela vai aqui dentro. É aqui que você vai trabalhar em todas as lições.
    </html>
    Fecha a página. Fim.

    Abrir e fechar

    <body> abre a caixa. </body> fecha — repare na barra /. Tudo o que está entre as duas fica dentro.

    Os espaços no começo das linhas (o recuo) mostram o que está dentro do quê. Eles não mudam a página, mas deixam o código fácil de ler.

    Títulos e texto

    O HTML tem seis tamanhos de título: de h1 (o mais importante) até h6 (o menos importante). E o p é o texto normal.

    Os seis títulos

    h1 — Título da página

    h2 — Capítulo

    h3 — Parte do capítulo

    h4 — Parte menor

    h5 — Ainda menor
    h6 — O menor de todos

    p — Um parágrafo de texto normal.

    1Pense como um livro

    • h1 é o nome do livro. Use só um por página.
    • h2 são os capítulos.
    • h3 são as partes de cada capítulo… e assim por diante.

    Escolha pela importância, não pelo tamanho

    Não use h4 só porque quer uma letra menor. O tamanho da letra se muda depois, com CSS. No HTML, você escolhe o título pela importância.

    Atalho Emmet: um depois do outro

    Listas

    Existem dois tipos de lista: com bolinhas e com números. Cada item da lista é um li.

    ul
    Lista não ordenada: com bolinhas. A ordem não importa (ex.: lista de compras).
    ol
    Lista ordenada: com números. A ordem importa (ex.: passo a passo de uma receita).
    li
    Um item da lista. Fica sempre dentro de um ul ou de um ol.

    Imagens e atributos

    A tag img coloca uma imagem na página. Mas ela precisa de uma informação a mais: qual imagem mostrar. Para isso servem os atributos.

    1O que é um atributo?

    Atributo é uma informação extra que vai dentro da tag de abertura. Sempre no formato nome="valor", com o valor entre aspas.

    <img src="flor.png" alt="Uma flor">
    • a tag
    • nome do atributo
    • valor (entre aspas)
    src
    Vem de source, “fonte”: de onde vem a imagem. É o endereço da imagem.
    alt
    Texto alternativo: descreve a imagem. Aparece se a imagem não carregar, e é lido em voz alta por programas que ajudam pessoas cegas.

    O img não fecha

    Repare: não existe </img>. A imagem não tem nada “dentro” dela, então a tag não precisa fechar.

    O que é CSS

    Na aula 1, você fez a estrutura da página com HTML: o que existe nela. Agora vem o CSS: a aparência. Cor, tamanho da letra, espaços, bordas.

    HTML
    O corpo da página: títulos, textos, listas, imagens. Diz o que tem.
    CSS
    A roupa da página: cores, letras, espaços. Diz como fica.

    1Abra o seu site de novo

    1. Abra o vscode.dev

      Menu ☰ → File → Open Recent (Abrir recente) → meu-site. Se não aparecer, use File → Open Folder… e escolha a pasta meu-site de novo.

    2. Permita de novo

      O navegador pode pedir permissão outra vez. Clique no botão que permite editar os arquivos.

    3. Abra o index.html

      Clique nele na coluna da esquerda. Abra também a página no Chrome, como na aula 1 (app Arquivos → dois cliques).

    2Onde escrever o CSS

    Para começar, o CSS vai dentro de uma tag <style>, que fica no head. O head guarda informações sobre a página, e o CSS é isso: uma informação de como a página deve ficar. Ele não aparece na tela.

    Atalho Emmet (no head, embaixo do title)

    Digitestyle+Tab→vira:

    Por que vira isso?

    • styleé o nome da tag, igual a p ou h1: o Emmet abre, fecha e deixa o cursor no meio. Aperte Enter para abrir espaço e escrever o CSS dentro.

    3Uma regra de CSS

    O CSS é feito de regras. Cada regra diz: “esta parte da página fica assim”.

    h1 { color: blue; }
    • seletor: qual parte muda
    • propriedade: o que muda
    • valor: como fica
    h1
    O seletor: é o nome da tag do HTML. Esta regra vale para todos os h1 da página.
    { }
    As chaves abrem e fecham a regra, como a abertura e o fechamento de uma tag.
    color: blue;
    Propriedade, dois pontos :, valor, e termina com ponto e vírgula ;. Aqui: “a cor da letra é azul”.

    Digite no seu index.html (só o que está no head mudou):

    O CSS fala inglês

    color quer dizer cor, blue quer dizer azul. Se escrever cor: azul;, não funciona. E se nada mudou, confira: faltou o ;? Faltou fechar a chave }? Salvou (Ctrl + S) e recarregou (Ctrl + R)?

    Cores

    Duas propriedades mudam cores: color muda a cor da letra, e background-color muda a cor do fundo.

    1Cores pelo nome (em inglês)

    2Cores pelo código

    Os nomes são poucos. Para ter qualquer cor, usamos um código que começa com # e tem 6 letras ou números, como #1C6EA4. Você não precisa decorar: copie de uma paleta.

    O vscode.dev mostra a cor

    Ao lado de cada cor escrita no CSS aparece um quadradinho colorido. Passe o mouse em cima dele para abrir um seletor de cores e escolher com o mouse.

    4Pintar o fundo da página

    Lembra que o body é o corpo da página, onde fica todo o conteúdo? Se o CSS pintar o fundo do body, a página inteira muda de cor.

    Quem pinta é o CSS

    O body continua sendo a estrutura (HTML). A cor de fundo é do CSS. A regra só está dizendo: “pinte o fundo do corpo”.

    Cuidado com letra clara em fundo claro: fica difícil de ler. Use letra escura em fundo claro, ou letra clara em fundo escuro.

    margin: espaço de fora
    border: a borda
    padding: espaço de dentro
    o conteúdo (o texto)

    1Emmet para espaços e bordas

    Atalhos Emmet

    Digitep20+Tab→vira:
    Digitem20+Tab→vira:
    Digitebd++Tab→vira:
    Digitebdrs+Tab→vira:

    Por que vira isso?

    • p20padding de 20px: espaço de dentro, entre o texto e a borda.
    • m20margin de 20px: espaço de fora, entre esta caixa e as outras.

    2Centralizar a página

    Numa tela grande, o texto fica esticado de um lado ao outro. Duas linhas no body resolvem:

    max-width: 700px;
    A página pode ter no máximo 700px de largura.
    margin: 0 auto;
    Nenhum espaço em cima e embaixo (0). Dos lados, auto: o navegador divide o espaço que sobra igual dos dois lados. Resultado: a página fica no meio.

    Use letras minúsculas, sem espaço e sem acento. Para juntar palavras, use hífen: cor-favorita, foto-perfil. A mesma classe pode ser usada em vários elementos, até de tags diferentes.

    No img há display: block;. A imagem normalmente fica “na linha”, como uma palavra. Com display: block, ela vira uma caixa inteira, e aí o margin: 0 auto; consegue colocar ela no meio.

    3Atualizar a página publicada

    Se você publicou a página na aula 1, dá para atualizar o mesmo endereço:

    1. Abra o seu repositório

      Em github.com, entre no repositório minha-pagina e clique no arquivo index.html.

    2. Clique no lápis

      O ícone de lápis (Edit this file), no canto de cima do código.

    3. Troque o código

      Clique no código do GitHub, aperte Ctrl + A e Delete. No vscode.dev, Ctrl + A e Ctrl + C. Volte no GitHub e Ctrl + V.

    4. Salve

      Clique em Commit changes… e em Commit changes de novo. Em 1 ou 2 minutos, o seu endereço mostra a página nova.
