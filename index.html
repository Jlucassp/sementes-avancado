    Antes de começar

    Preparar o vscode.dev

    Aqui você vai escrever código de verdade, como os programadores fazem. Leia cada lição nesta tela e faça no vscode.dev, em outra aba.

    Dica: uma janela de cada lado

    Abra o vscode.dev em uma janela nova (Ctrl + N). No Chromebook, Alt + [ encosta a janela à esquerda e Alt + ] encosta à direita. Assim você lê e digita ao mesmo tempo.

    1Abrir e preparar

    1. Abra o vscode.dev

      Abra uma aba nova (Ctrl + T), escreva vscode.dev e aperte Enter. Não precisa instalar nada.

    2. Abra uma pasta para o seu site

      Clique no menu ☰ (três risquinhos, no canto de cima, à esquerda) → File → Open Folder… (quer dizer Arquivo → Abrir pasta).

      Na janela que abrir: entre em Meus arquivos, clique em Nova pasta, dê o nome meu-site e clique em Abrir.

      O navegador vai pedir permissão. Clique no botão que permite editar os arquivos (por exemplo, Editar arquivos / Edit files). Se aparecer “Do you trust the authors…?”, clique em Yes, I trust the authors.

    3. Crie o arquivo index.html

      Na coluna da esquerda aparece o nome da pasta, MEU-SITE. Passe o mouse em cima dele: aparecem ícones pequenos. Clique no primeiro (New File… = Novo arquivo), escreva index.html e aperte Enter.

    4. Salve sempre

      Aperte Ctrl + S depois de cada mudança. Se a aba do arquivo mostra uma bolinha ● ao lado do nome, é porque ainda não salvou.

    5. Veja a sua página

      Abra o app Arquivos do Chromebook → Meus arquivos → meu-site → dê dois cliques em index.html. A página abre no Chrome.

      Mudou o código? Faça assim: Ctrl + S no vscode.dev → volte na aba da página → Ctrl + R para recarregar.

    O nome precisa terminar em .html

    Só assim o vscode.dev sabe que o arquivo é HTML. Confira no canto de baixo, à direita: tem que estar escrito HTML. Sem isso, o Emmet não funciona.

    Lição 1

    A estrutura da página

    Toda página HTML tem um esqueleto: html, head e body. São caixas, uma dentro da outra.

    html — a página inteira
    head — a cabeça

    Informações sobre a página: o nome da aba, os acentos… Quase nada daqui aparece na tela.

    body — o corpo

    Tudo o que aparece na tela fica aqui dentro: títulos, textos, imagens, listas, links.

    1O Emmet escreve o esqueleto

    Com o arquivo index.html aberto e vazio:

    Atalho Emmet

    Digite!+Tab→vira:

    Por que vira isso?

    • !é o atalho para “página completa”. Em vez de uma tag só, o Emmet escreve o esqueleto inteiro de uma página HTML.

    2Entendendo cada parte

    <!DOCTYPE html>
    Avisa ao navegador: “isto é uma página HTML”. Fica sempre na primeira linha.
    <html lang="en">
    Abre a página inteira. O lang diz o idioma. Troque en (inglês) por pt-BR (português do Brasil).
    <head>
    A cabeça: guarda informações sobre a página.
    <meta charset="UTF-8">
    Faz os acentos e o ç aparecerem certinho.
    <meta name="viewport" …>
    Faz a página funcionar bem na tela do celular.
    <title>Document</title>
    O nome que aparece na aba do navegador. Troque Document pelo nome da sua página.
    <body> … </body>
    O corpo. Todo o conteúdo que aparece na tela vai aqui dentro. É aqui que você vai trabalhar em todas as lições.
    </html>
    Fecha a página. Fim.

    Abrir e fechar

    <body> abre a caixa. </body> fecha — repare na barra /. Tudo o que está entre as duas fica dentro.

    Os espaços no começo das linhas (o recuo) mostram o que está dentro do quê. Eles não mudam a página, mas deixam o código fácil de ler.

    Lição 2

    Títulos e texto

    O HTML tem seis tamanhos de título: de h1 (o mais importante) até h6 (o menos importante). E o p é o texto normal.

    Os seis títulos

    h1 — Título da página

    h2 — Capítulo

    h3 — Parte do capítulo

    h4 — Parte menor

    h5 — Ainda menor
    h6 — O menor de todos

    p — Um parágrafo de texto normal.

    1Pense como um livro

    • h1 é o nome do livro. Use só um por página.
    • h2 são os capítulos.
    • h3 são as partes de cada capítulo… e assim por diante.

    Escolha pela importância, não pelo tamanho

    Não use h4 só porque quer uma letra menor. O tamanho da letra se muda depois, com CSS. No HTML, você escolhe o título pela importância.

    2Emmet para títulos e textos

    Atalho Emmet

    Digiteh1+Tab→vira:

    Por que vira isso?

    • h1é o nome da tag. O Emmet escreve a abertura <h1>, o fechamento </h1> e deixa o cursor no meio. Funciona igual com h2, h3… e p.

    Atalho Emmet: um depois do outro

    Digiteh2+p+Tab→vira:

    Por que vira isso?

    • h2cria um título de capítulo.
    • +quer dizer “e depois”: coloca a próxima tag logo embaixo, no mesmo nível.
    • pcria um parágrafo.

    Depois de apertar Tab, o cursor fica dentro do h2. Escreva o título e aperte Tab de novo: o cursor pula para dentro do p.

    Extra: texto de enchimento

    Digite lorem + Tab dentro de um p: o Emmet escreve um texto falso em latim (“Lorem ipsum…”). Serve para testar a página antes de ter o texto de verdade. lorem10 escreve só 10 palavras.

    Lição 3

    Listas

    Existem dois tipos de lista: com bolinhas e com números. Cada item da lista é um li.

    ul
    Lista não ordenada: com bolinhas. A ordem não importa (ex.: lista de compras).
    ol
    Lista ordenada: com números. A ordem importa (ex.: passo a passo de uma receita).
    li
    Um item da lista. Fica sempre dentro de um ul ou de um ol.

    1Lista com bolinhas

    Atalho Emmet

    Digiteul>li*3+Tab→vira:

    Por que vira isso? Leia da esquerda para a direita:

    • ulcria a lista com bolinhas.
    • >quer dizer “dentro de”: o que vem depois fica dentro do ul. Por isso os li aparecem com recuo.
    • licria um item.
    • *3quer dizer “repita 3 vezes”. Por isso aparecem três li. Quer cinco itens? Use *5.

    O cursor começa dentro do primeiro li. Escreva o item e aperte Tab para pular para o próximo.

    Lição 4

    Imagens e atributos

    A tag img coloca uma imagem na página. Mas ela precisa de uma informação a mais: qual imagem mostrar. Para isso servem os atributos.

    1O que é um atributo?

    Atributo é uma informação extra que vai dentro da tag de abertura. Sempre no formato nome="valor", com o valor entre aspas.

    <img src="flor.png" alt="Uma flor">
    • a tag
    • nome do atributo
    • valor (entre aspas)
    src
    Vem de source, “fonte”: de onde vem a imagem. É o endereço da imagem.
    alt
    Texto alternativo: descreve a imagem. Aparece se a imagem não carregar, e é lido em voz alta por programas que ajudam pessoas cegas.

    O img não fecha

    Repare: não existe </img>. A imagem não tem nada “dentro” dela, então a tag não precisa fechar.

    2Emmet para imagem

    Atalho Emmet

    Digiteimg+Tab→vira:

    Por que vira isso?

    • imgo Emmet sabe que imagem sempre precisa de src e alt, então já escreve os dois atributos, com as aspas vazias.
    • |O cursor fica entre as aspas do src. Cole o endereço, aperte Tab e o cursor pula para o alt.

    3Pegue uma imagem

    Escolha uma figura e toque em Copiar endereço. Depois, no vscode.dev, clique entre as aspas do src="" e aperte Ctrl + V para colar.

    Por que o endereço é tão comprido?

    Estes endereços começam com data:image/svg+xml, porque a própria imagem está escrita dentro do endereço. Assim ela funciona sem internet e sem baixar nada.

    Normalmente, o src é curto: o nome de um arquivo na sua pasta (src="foto.jpg") ou um endereço da internet (src="https://…/foto.jpg").

    Links

    Um link é um texto (ou imagem) que você clica para ir a outra página. É o que faz a internet ser uma “rede”: as páginas ligadas umas às outras.

    <a href="https://pt.wikipedia.org/wiki/Fortaleza">Conheça Fortaleza</a>
    a
    A tag do link. Vem de anchor, “âncora”.
    href
    O atributo com o endereço para onde o link leva. Precisa começar com https://.
    Conheça Fortaleza
    O texto entre a abertura e o fechamento é o que aparece na tela para clicar.

    Lição 7

    Primeiro CSS

    O HTML é a estrutura da página: o que existe nela. O CSS é a aparência: cor, tamanho, letra. Pense assim: o HTML é o corpo, o CSS é a roupa.

    1Onde escrever o CSS

    Para começar, o CSS vai dentro de uma tag <style>, no head (ele não aparece na tela, só muda a aparência):

    body / h1
    O seletor: diz qual parte da página vai mudar.
    { }
    As chaves guardam as regras dessa parte.
    color: #1C6EA4;
    Propriedade (o que muda) : valor (como fica) e termina com ;.

    Repare

    A cor de fundo é do CSS. O body continua sendo o corpo da página (HTML). Aqui o CSS só está dizendo: “pinte o fundo do body”.

    2Emmet também funciona no CSS

    Atalho Emmet (dentro das chaves)

    Digitebgc+Tab→vira:
    • bgcbackground-color: cor de fundo. #fff é branco. Troque pelo código da cor que quiser.
    • cc + Tab vira color: #000; — a cor da letra (#000 é preto).
